# Проект "Сапёр" (Minesweeper)

Настоящий проект представляет собой программную реализацию классической логической игры "Сапёр". Разработка выполнена на языке программирования C с интеграцией графической библиотеки открытого исходного кода Raylib. Проект демонстрирует применение базовых структур данных, алгоритмов на графах и принципов построения графического пользовательского интерфейса (GUI).

## 1. Общее описание

Цель игры заключается в обнаружении всех пустых (безопасных) ячеек на двумерном игровом поле, не задев при этом скрытые мины. Игрок ориентируется на числовые значения, появляющиеся в открытых ячейках и указывающие на суммарное количество мин в смежных координатах (по горизонтали, вертикали и диагонали). 

Проект разработан с упором на автономность: компиляция и запуск не требуют предварительной конфигурации сложных сред разработки, все необходимые статические библиотеки включены в состав репозитория.

## 2. Функциональные возможности

Программа предоставляет следующий набор возможностей:
* **Многоуровневая система сложности:** * Easy (поле 10x10 ячеек, 15 мин).
  * Medium (поле 15x15 ячеек, 40 мин).
  * Hard (поле 20x20 ячеек, 80 мин).
* **Адаптивный рендеринг:** Программная логика автоматически пересчитывает размер окна и габариты игровых ячеек в зависимости от выбранного уровня сложности и разрешения монитора пользователя. Игровое поле всегда центрируется.
* **Безопасный старт:** Имплементирован алгоритм отложенной генерации мин. Распределение взрывных устройств происходит строго после первого взаимодействия пользователя с полем, при этом координаты первой выбранной ячейки принудительно исключаются из зоны минирования.
* **Каскадное открытие ячеек:** Реализован алгоритм заливки (Flood-fill). При открытии ячейки, не имеющей смежных мин, программа рекурсивно открывает все соседние безопасные зоны, значительно ускоряя игровой процесс.

## 3. Архитектура и структуры данных

В основе логики игрового поля лежит двумерный массив структур `Cell`. Каждая ячейка хранит собственное состояние:
* Флаг наличия мины (`isMine`).
* Флаг видимости для пользователя (`isRevealed`).
* Флаг пользовательской метки (`isFlagged`).
* Целочисленное значение смежных мин (`neighborMines`).

Управление состояниями приложения реализовано через конечный автомат (State Machine), переключающий контекст рендеринга между главным меню и активной игровой сессией.

## 4. Пользовательский интерфейс и управление

Взаимодействие с приложением осуществляется посредством компьютерной мыши и клавиатуры:
* **Левая кнопка мыши (LMB):** Открытие выбранной ячейки / взаимодействие с элементами меню.
* **Правая кнопка мыши (RMB):** Установка или снятие предупреждающего флага на закрытой ячейке.
* **Клавиша [R]:** Принудительный перезапуск текущей игровой сессии с перегенерацией минного поля.
* **Клавиша [M]:** Прерывание текущей игры и возврат на экран выбора уровня сложности.

## 5. Инструкция по сборке и запуску

Проект ориентирован на операционные системы семейства Windows. Для компиляции исходного кода требуется установленный компилятор GCC (MinGW).

**Порядок действий:**
1. Выполните клонирование репозитория на локальный накопитель.
2. Откройте корневую директорию проекта.
3. Запустите командный скрипт `build.bat`. Данный скрипт автоматически выполнит линковку исходного кода `main.c` с библиотекой Raylib (`libraylib.a`) и необходимыми системными зависимостями (`opengl32`, `gdi32`, `winmm`).
4. В случае успешного завершения процесса сборки в директории будет сгенерирован исполняемый файл `minesweeper.exe`. Запустите его для инициализации приложения.
